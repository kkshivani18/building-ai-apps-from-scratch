# Context Engineering Exercises

Run these scripts from the repository root with the course virtual environment:

```powershell
.\ai-course\Scripts\python.exe "context engg\exercises\token_waste_detector.py"
.\ai-course\Scripts\python.exe "context engg\exercises\semantic_deduplication.py"
.\ai-course\Scripts\python.exe "context engg\exercises\context_replay.py"
.\ai-course\Scripts\python.exe "context engg\exercises\priority_tool_selector.py"
.\ai-course\Scripts\python.exe "context engg\exercises\context_compressor_benchmark.py"
```

Each script uses the nearest Build It module and produces a small measurable
demonstration for one exercise.
