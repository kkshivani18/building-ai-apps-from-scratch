# Prompt Optimizer

Rewrite the draft prompt into a precise, production-ready prompt.

Preserve the original intent. Add appropriate:

- Specific role and expertise
- Context
- Clear task
- Positive and negative constraints
- Output format
- Target audience
- Examples
- Edge-case handling
- Uncertainty behavior

Do not invent requirements.

Write a Python function to compare Redis and Memcached for a beginner.
